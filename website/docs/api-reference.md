# API Reference

This reference is generated directly from the Venice AI Python SDK's source docstrings.

Browse by module using the sidebar. The resource classes (`chat`, `image`, `audio`,
`video`, `music`, `embeddings`, `decisions`, `characters`, `augment`, `billing`,
`x402`, and more) live under `venice_ai.resources`; error classes are in `venice_ai.exceptions`, and
cost-tracking helpers are in `venice_ai.costs`.
